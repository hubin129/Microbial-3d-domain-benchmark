# System Requirements

- Linux workstation or an equivalent environment with Python, R, Java and C++ support.
- The benchmark was recorded on Ubuntu 20.04.2 LTS with an Intel Xeon W-2175 2.50 GHz CPU and 200 GB RAM.
- Python 3.8-3.10, R 4.0-4.2 and OpenJDK 11 were used for the corresponding modules.
- GCC 9-11, Cython and Python development headers are required to compile the EVRC extension.
- Caller-specific dependencies are listed in the upstream tool documentation and in `THIRD_PARTY_SOURCES.md`.
