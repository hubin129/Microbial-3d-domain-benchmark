# Input Layout and Naming Rules

## Representative Inputs

Release 1.1.1 provides one representative chromosome for each species:

- Yeast `chr1`: Hi-C at 500, 1,000, 2,000, 5,000 and 10,000 bp; Micro-C at 200 and 500 bp.
- *E. coli* `NC_000913.3`: Hi-C at 500, 1,000, 2,000, 5,000 and 10,000 bp; Micro-C at 200 and 500 bp.
- Expression module: expression tables and matching reference GFF files for both species.
- Yeast functional module: ATAC-seq bigWig, GO annotations and KEGG mappings.

These files are the processed starting inputs used in the benchmark. Unprocessed FASTQ files are outside the scope of this protocol. Caller outputs, hierarchical domains, EVRC reconstructions, coolpup files, SSIM intermediates and statistical results are generated by their respective modules and are not repackaged as inputs.

The complete file list and per-file SHA256 values are recorded in `docs/included_input_data.tsv`.

## Contact Matrices

Place balanced `.cool` files under:

```text
progress/1-balanced-cool/<species>/<data_type>/<resolution>/<chrom>.cool
```

The species labels used in this study are `BY4741` and `E.coli`; assay labels are `HiC` and `Micro-C`. Yeast chromosomes use `chr1` through `chr16`, and *E. coli* uses `NC_000913.3`. File names retain the resolution, for example `chr1_1000.cool` and `NC_000913.3_1000.cool`.

## Raw Caller Outputs

Place standardized three-column BED files under:

```text
progress/1-TAD-data/<species>/<method>/<data_type>/<resolution>/<chrom>.bed
```

Files must contain at least `chromosome`, `start` and `end`. Coordinates are zero-based half-open. Exact duplicate intervals are retained only once, and invalid coordinates are excluded from evaluation.

`progress/2-analyse/summary.xlsx` records domain counts and OOM, Timeout or zero-output states for each method and condition. `time_memory-useage.xlsx` records resource monitoring results. These workbooks describe the benchmark inputs and must be regenerated for new data.

## Hierarchical Domains

`3-domain-level.py` writes standardized files to:

```text
progress/1-TAD-level-data/<species>/<method>/<data_type>/<resolution>/<chrom>.bed
```

The output contains at least `chromosome`, `start`, `end` and `level`.

## EVRC

Prepare a balanced dense matrix for each chromosome. Each input directory should contain one chromosome. PDB outputs should be written to:

```text
progress/1-EVRC-data/<species>/<data_type>/<resolution>/<chrom>/
```

## coolpup

Place `.clpy` files under:

```text
progress/1-coolpup-data/<species>/2-coolpup/<data_type>/<resolution>/<method>/
```

Yeast file names should include the chromosome, for example `HiC_chr1_1000.clpy`. *E. coli* has one chromosome and can use condition-level files mapped to `NC_000913.3`.

## Expression and Functional Data

Place these inputs under `progress/1-expression-data/`. The release provides `BY4741-TPM-FPKM.tsv`, `Ecoli_expression_annotated_readable.tsv` and the corresponding GFF files as starting inputs for canonical mapping. Run `A5-prep-canonical-gene-expression.py` to create canonical gene tables with unique S288C or ASM584v2 gene identifiers and coordinates under `gene-level/`. Downstream analyses retain numeric `TPM > 0` genes. The yeast ATAC-seq bigWig is `progress/1-expression-data/ATAC/A5-1.rmdup.last.bw`.
